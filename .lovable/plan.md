# طلبات التوظيف (Job Applications) — خطة التنفيذ

بند جديد في الموارد البشرية: رابط تقديم عام + QR بالشعار، يستقبل طلبات التوظيف من أي شخص (بدون تسجيل دخول)، ويظهر للموارد البشرية بشاشة بنمط Microsoft Dynamics FinanceShell، مع إشعار فوري لبوابة المالك ولدائرة الموارد البشرية.

## 1. نموذج التقديم العام
مسار عام جديد: `/jobs/:slug` (مثال: `unifyerp.app/jobs/malaky`) — نسخة رقمية من نموذج HRM-01 الورقي المرفق:

- **البيانات الشخصية:** الاسم، رقم الهوية، الجنس، تاريخ الولادة، مكان الولادة، الحالة الاجتماعية، عدد الأولاد، العنوان، رقم الهاتف، البريد.
- **الوظيفة المطلوبة** + تاريخ التقديم (تلقائي).
- **المؤهلات العلمية:** درجة، تخصص، مكان الدراسة، من/إلى (صفوف متعددة).
- **البرامج التدريبية:** اسم الدورة، المؤسسة، عدد الساعات، من/إلى (صفوف متعددة).
- **اللغات:** لغة + مستوى المحادثة/القراءة/الكتابة (جيد/متوسط/ضعيف).
- **خبرات العمل السابقة:** مكان العمل، الوظيفة، من/إلى (صفوف متعددة).
- **المعرفون:** الاسم، هاتف، محمول، بريد.
- **تفضيلات:** فترة الدوام (صباحي/مسائي)، نوع الوظيفة (دائم/مؤقت)، موقع العمل (مطبخ/كاونتر/تنظيف)، التدخين، العمل يوم الجمعة، رخصة القيادة ونوعها.
- **مرفقات:** سيرة ذاتية / فحص طبي (اختياري، رفع ملف).

الصفحة: عربية RTL، موبايل أولاً، شعار الشركة أعلى الصفحة، تحقق من الحقول الإجبارية (الاسم، الهوية، الهاتف، الوظيفة)، وشاشة شكر بعد الإرسال.

## 2. شاشة الموارد البشرية — FinanceShell
بند جديد «طلبات التوظيف» داخل الموارد البشرية على مسار `/hr/job-applications`، بتصميم Dynamics FinanceShell (رأس صفحة بشريط لوني، بطاقات KPI، جدول كثيف مع فلاتر):

- **KPI:** طلبات اليوم / هذا الشهر / قيد المراجعة / مقبولة / مرفوضة.
- **جدول:** التاريخ والساعة، الاسم، الهوية، الهاتف، الوظيفة المطلوبة، العمر، الفرع/الموقع، الحالة.
- **فلاتر:** بحث نصي، الوظيفة، الحالة، الفترة الزمنية، الفرع.
- **بطاقة تفصيلية** (Drawer) تعرض كل بيانات الطلب بتنسيق النموذج الورقي + المرفق + زر طباعة.
- **إجراءات:** تغيير الحالة (جديد / قيد المراجعة / مقابلة / مقبول / مرفوض) + ملاحظة سبب الرفض، وتصدير Excel.
- **لوحة الرابط والـ QR:** الرابط العام، زر نسخ، تفعيل/إيقاف الرابط، و**QR بالشعار في المنتصف** بإطار وهوية الشركة، مع زر تحميل PNG وزر طباعة بوستر A4 (عنوان «انضم لفريقنا» + الشعار + QR).

## 3. الإشعارات
عند وصول أي طلب جديد:
- إشعار لبوابة المالك (يظهر في جرس الإشعارات الحالي) بعنوان «طلب توظيف جديد» واسم المتقدم، ورابط يفتح الطلب مباشرة.
- إشعار لدائرة الموارد البشرية (كل من له دور `hr_manager` / `admin`).
يُنفَّذ عبر Trigger في قاعدة البيانات يكتب في نفس جدول الإشعارات المستخدم حالياً، فيصل فوراً (Realtime) وكذلك كإشعار Push لمن فعّله.

## التفاصيل التقنية
- جدول `job_application_links`: `owner_id`, `slug` فريد, `title`, `is_active`, `branch_id?` — يسمح لكل شركة (وكل فرع لاحقاً) برابط مستقل.
- جدول `job_applications`: حقول النموذج أعلاه (المؤهلات/الدورات/الخبرات/اللغات كـ `jsonb[]`)، `status`, `review_notes`, `reviewed_by`, `attachment_path`, `owner_id`, `link_id`, `created_at`.
- GRANT + RLS: `INSERT` للـ `anon` عبر Edge Function عام (`submit-job-application`) يتحقق من الـ slug ومن معدل الإرسال ويكتب بصلاحية الخدمة — بدون فتح الجدول للقراءة العامة. `SELECT/UPDATE` لأصحاب الحساب و`hr_manager`/`admin` فقط ضمن نفس `owner_id`.
- المرفقات في Storage bucket خاص `job-applications` (غير عام، قراءة بروابط موقّعة).
- QR: مكوّن يعتمد `qrcode.react` الموجود مسبقاً مع تركيب الشعار في المنتصف (`imageSettings`) وتصدير PNG عبر Canvas.
- ملاحظة: رابط Google Forms المرسل يُستخدم كمرجع لمحتوى النموذج فقط؛ التقديم يتم داخل النظام حتى تصل الطلبات والإشعارات لقاعدة البيانات مباشرة.
