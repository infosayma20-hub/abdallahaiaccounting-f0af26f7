# بطاقة تقييم الموظفين في بوابة المالك

## النتيجة
- تظهر بطاقة **«تقييم الموظفين»** ضمن قسم الموارد البشرية في «المزيد» لمصعب وكمال فقط.
- تفتح البطاقة شاشة قراءة فقط، مناسبة للجوال، تعرض الموظف، المدير المقيّم، المسمى، التاريخ، المعدل، الملاحظات، المعايير والحالة.
- يصل لمصعب وكمال إشعار فوري عند اكتمال تقييم موظف جديد، ويفتح الإشعار التقييم نفسه داخل بوابة المالك.

## التنفيذ
1. إضافة صلاحية مستقلة قابلة للتعطيل لمشاهدة تقييمات الموظفين، وربطها بحسابي مصعب وكمال الحاليين دون منحها لباقي مستخدمي البوابة.
2. إضافة قراءة آمنة عبر بوابة المالك؛ لا وصول مباشر واسع لبيانات الموارد البشرية، ولا عرض للمسودات المحفوظة مؤقتًا.
3. إنشاء شاشة تقييمات مخصصة للبوابة ببطاقات جوال، بحث، ملخص للمعدل، وتفاصيل قابلة للفتح تشمل الملاحظات والمعايير.
4. إضافة البطاقة إلى «المزيد» فقط لمن لديه الصلاحية.
5. إضافة تنبيه عند تحوّل النموذج من مسودة محفوظة إلى تقييم مكتمل، أو عند حفظ تقييم مكتمل مباشرة، مع منع تكرار التنبيه لنفس التقييم والمستلم.
6. ربط مسار إشعار الجرس بالشاشة الجديدة والتقييم المحدد.

## ضوابط السلامة
- التقييمات قراءة فقط في بوابة المالك؛ لا تعديل ولا اعتماد ولا حذف.
- عزل كامل حسب الشركة وحساب المستلم.
- لا تغيير على التقييمات التاريخية أو مسارات الموارد البشرية الحالية.
- الإشعار لا يُرسل عند الحفظ التلقائي أو المسودة، ولا يتكرر عند تحديث التقييم لاحقًا.

## التحقق
- اختبار دخول مصعب وكمال وظهور البطاقة، وعدم ظهورها لحساب بوابة غير مخوّل.
- اختبار عرض التقييمات والملاحظات والمعايير على عرض جوال.
- اختبار إنشاء تقييم مكتمل ووصول إشعار واحد لكل مالك وفتحه للتقييم الصحيح.
- فحص سلامة البناء والاختبارات وسجل الأخطاء بعد التنفيذ.
