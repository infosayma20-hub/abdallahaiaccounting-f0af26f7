# رسائل داخلية بين الأقسام (Amwali Internal Messages)

## الفكرة العامة
شاشة "الرسائل الداخلية" داخل البرنامج تسمح لأي مستخدم (مثل HR) بإرسال رسالة أو تعليمات لموظف/قسم آخر (مثل المحاسبة/المالك)، مع إمكانية:
- توجيه الرسالة لشخص محدد بالاسم، أو لكل موظفي المحاسبة (بالدور)، أو للمالك.
- إرفاق تاريخ استحقاق/تذكير → يظهر تنبيه للمستلم في ذلك اليوم.
- ربط الرسالة اختيارياً بموظف/قرض/فاتورة (سياق سريع).
- حالات: جديد → مقروء → تم التنفيذ.
- ردود متسلسلة (thread) داخل نفس الرسالة.

## تدفق الاستخدام (سيناريو رهام)
1. رهام تفتح "رسائل داخلية" → "رسالة جديدة".
2. تختار المستلم: سارة (بالاسم) — أو "المحاسبة" كدور — مع نسخة للمالك.
3. الموضوع: "صرف القرض الحسن لأدهم قرارية".
4. النص: "يرجى صرف القرض مع راتب شهر 7".
5. تحدد "تاريخ التذكير": 2026-07-28 (اختياري).
6. ترسل → سارة تشوف الرسالة فوراً في صندوقها + تنبيه (bell) + إشعار push، وفي التاريخ المحدد يرجع يذكّرها.
7. سارة تقدر ترد/تعلّمها "تم التنفيذ" فتنغلق.

## أماكن الوصول
- عنصر في الشريط العلوي (أيقونة رسائل مع عدّاد غير مقروء).
- صفحة كاملة `/internal-messages` بقائمة الوارد/المرسل/الأرشيف.
- بطاقة "رسائلي" في لوحة HR ولوحة المحاسبة.

## الصلاحيات والخصوصية
- كل مستخدم يشوف رسائله فقط (وارد ومرسل) — RLS صارمة.
- المالك/الأدمن يقدر يشوف كل رسائل شركته لأغراض التدقيق.
- تُعزل بالكامل حسب `dataOwnerId` (لا تسريب بين الشركات).

## التقنية (باختصار)
- جدولان جديدان: `internal_messages` (الرسالة الأم) و `internal_message_recipients` (مستلم لكل نسخة، مع `read_at`، `done_at`، `remind_at`).
- RLS: المرسل والمستلمون فقط + الأدمن.
- Realtime على جدول المستلمين → تحديث فوري للعدّاد والصندوق.
- Cron يومي: يحوّل الرسائل التي وصل تاريخ تذكيرها إلى إشعار (bell + push للجهاز عبر `notification_queue` القائم).
- شاشة React جديدة + Hook `useInternalMessages` + Badge في الشريط العلوي.

## ما سيتم بناؤه (بالترتيب)
1. Migration: جدولا الرسائل + المستلمين + RLS + Realtime + دالة `send_internal_message()`.
2. Edge/Cron: `internal-message-reminders` (يومي، يبعث إشعارات في تاريخ التذكير).
3. صفحة `/internal-messages` (وارد | مرسل | أرشيف) + منشئ رسالة (اختيار مستلم بالاسم/الدور، تاريخ تذكير، ربط بموظف/قرض).
4. Badge غير مقروء في الشريط العلوي مع Realtime.
5. زر "رسالة إلى المحاسبة" مختصر داخل شاشة القرض الحسن للموظف (اختصار لتعبئة السياق تلقائياً).

## خارج النطاق (لاحقاً إذا حبيتوا)
- مرفقات ملفات (PDF/صور).
- رسائل جماعية للمجموعات المخصصة.
- WhatsApp/Email خارجي — حالياً داخل البرنامج فقط + إشعار push.
