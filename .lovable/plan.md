# خطة بناء Sparta ERP في المشروع الجديد (Remix) — النسخة المُحدّثة

الهدف: بعد ما تعمل Remix لمشروع أموالي بـ `Include project history: OFF`، أنا بحول المشروع لـ **Sparta ERP** كامل — نفس قوة أموالي بالضبط، بهوية سبارتا (عنابي #8B1E3F + وردي ناعم #FBEAF1 + لوجو sparta-logo.png)، وقاعدة بيانات نظيفة جديدة بأسماء جداول عادية بدون أي prefix.

---

## المرحلة 1 — التنظيف والـ White-Label

### 1.1 إزالة كل ما يخص الملكي / أموالي
- حذف كل ملفات `src/components/sparta/*` القديمة وإعادة بنائها كـ Shell رئيسي.
- حذف كل ما يخص: Malaky / POS / Print Bridge / KDS / Qamar / Wheels / Sami AI / منيو QR / WhatsApp Sharing / SOA Public Pages / بوابات المطاعم / Travel Booking.
- استبدال `src/constants/brand.ts` و `BrandLogo` بقيم سبارتا.
- استبدال `index.html` (title, manifest, theme-color, favicon).
- نقل `sparta-theme.css` ليصبح هو `index.css` الرئيسي.

### 1.2 قاعدة بيانات جديدة نظيفة
- حذف **كل** الجداول (264 جدول) وإعادة بناء بأسماء طبيعية: `invoices`, `employees`, `accounts`, `journal_entries`, `customers`, `products`, `warehouses`, …
- كل جدول له `company_id` + RLS + GRANT statements في نفس migration.
- `user_roles` جدول منفصل (تجنب privilege escalation).

### 1.3 شاشة تسجيل الدخول و Onboarding
- لوجو سبارتا + خلفية تدرج العنابي/الوردي.
- Google Sign-In + Email/Password.
- Onboarding: اسم الشركة، العملة، السنة المالية.

## المرحلة 5 — الإشعارات (Notifications) ⭐ جديد

### 5.1 مركز الإشعارات الموحّد
- جدول `notification_log` + `notification_queue` + `notification_templates`.
- Realtime عبر Supabase Realtime.
- Bell icon في الـ Top bar مع unread counter.

### 5.2 أنواع الإشعارات
- مالية: فاتورة مستحقة، شيك مرتجع، شيك مستحق التحصيل، تجاوز سقف ذمم.
- مخزون: نفاد، اقتراب صلاحية دفعة، طلب تحويل.
- HR: طلب إجازة، تأخر، انتهاء عقد.
- CRM: lead جديد، مهمة متأخرة، اقتراب موعد مكالمة.
- ضريبية: استحقاق إقرار ضريبي.

### 5.3 قنوات التسليم
- داخل التطبيق (in-app).
- Email عبر Lovable Email.
- Push notifications (Web Push API).
- تفضيلات المستخدم لكل نوع وكل قناة.

## المرحلة 8 — المحاسب الضريبي (Tax Module) ⭐ جديد

### 8.1 إدارة الضرائب
- جدول `tax_categories` (VAT, Withholding, …).
- جدول `tax_settings` لكل شركة (النسبة، طريقة الحساب، التقريب).
- ربط كل صنف/خدمة بفئة ضريبية.

### 8.2 دفتر الضرائب (Tax Ledger)
- جدول `tax_ledger` يلتقط كل حركة ضريبية تلقائياً من الفواتير.
- ضريبة مخرجات (Output) من فواتير المبيعات.
- ضريبة مدخلات (Input) من فواتير المشتريات.

### 8.3 الإقرارات الضريبية (Tax Submissions)
- جدول `tax_submissions` لإقرارات الفترات.
- زر "إنشاء إقرار" يحسب آلياً: Output - Input = المستحق.
- حالات: مسودة → مقدم → مدفوع.
- إنشاء قيد محاسبي تلقائي عند الدفع.

### 8.4 تقارير ضريبية
- ملخص ضريبي شهري/ربعي/سنوي.
- تفصيل بفواتير المخرجات والمدخلات.
- تصدير بصيغة متوافقة مع متطلبات السلطة الضريبية الفلسطينية (16% VAT).
- تنبيهات استحقاق الإقرارات.

## المرحلة 9 — CRM (إدارة علاقات العملاء) ⭐ جديد — موسّع

### 9.1 إدارة الـ Leads
- جدول `leads` مع مصادر (Website, Referral, Cold Call, …).
- Lead scoring آلي.
- تحويل Lead → Opportunity → Customer.

### 9.2 إدارة الفرص (Opportunities / Pipeline)
- جدول `opportunities` + `opportunity_stage_history`.
- Kanban board للـ Pipeline (Qualification → Proposal → Negotiation → Won/Lost).
- توقع الإيرادات (Forecast).
- ربط مع الفواتير عند الإغلاق.

### 9.3 الأنشطة والمهام (Activities)
- جدول `activities` (مكالمات، اجتماعات، إيميل، مهام).
- Calendar view + تذكيرات.
- ربط مع Lead / Opportunity / Customer.

### 9.4 إدارة العملاء (Customers 360°)
- ملف موحّد لكل عميل: معلومات، تاريخ المعاملات، الفواتير، الذمم، الأنشطة، الملاحظات، المرفقات.
- تصنيف العملاء (VIP, Regular, At Risk).
- خط زمني (Timeline) لكل التفاعلات.

### 9.5 مهام خدمة العملاء (Customer Service)
- جدول `support_tickets` + `ticket_comments` + `ticket_attachments`.
- SLA tracking + escalation.
- قاعدة معرفة (Knowledge Base).

### 9.6 الحملات التسويقية (اختياري)
- جدول `campaigns` + ربط الـ Leads بالحملات.
- قياس ROI لكل حملة.

### 9.7 تقارير CRM
- معدل التحويل (Conversion Rate).
- متوسط دورة البيع.
- أداء المندوبين.
- خسارة الفرص + أسبابها.

## التفاصيل التقنية (للمختصين)

### Stack
- React 18 + Vite 5 + TypeScript + Tailwind v3

## أسئلة بعد ما تفتح المشروع الجديد

1. **اسم الشركة الأول للـ seed:** Sparta Trade؟
2. **العملة الأساسية:** شيكل / دولار / دينار / يورو؟
3. **VAT افتراضي:** 16% فلسطيني مفعّل؟ أم نتركه قابل للتفعيل من الإعدادات؟
4. **اللغة:** عربية فقط، أم عربي/إنجليزي قابل للتبديل؟
5. **Email للإشعارات:** نفعّل Lovable Email من اليوم الأول؟
6. **Mobile PWA:** لكل الموديولات أم Van Sales + HR + CRM فقط؟
