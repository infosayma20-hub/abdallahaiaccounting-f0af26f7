## ميزة جديدة: سياسات الرواتب المتعددة (Policies) + ربط الموظفين/الأقسام

البنية التحتية في قاعدة البيانات **جاهزة بالكامل**:
- جدول `hr_payroll_policies` موجود مع RLS كامل (`hr_manager`/`admin`/`super_admin` فقط للكتابة).
- `employees.payroll_policy_id` موجود كمفتاح ربط.
- تريغرات حماية: لا يمكن حذف السياسة الافتراضية، ولا حذف سياسة مربوطة بموظفين.
- قيد فريد: سياسة افتراضية واحدة لكل شركة.

**كل العمل سيكون UI فقط — بدون أي migrations.**

---

### 1) صفحة "سياسات الرواتب المتعددة" (جديدة)

مسار: `/payroll-settings/policies` (تبويب جديد داخل `PayrollSubNav` باسم **"السياسات"**)

**القائمة (Index):**
- بطاقات للسياسات: الاسم، الوصف، شارة "افتراضية"، شارة "نشطة"، عدد الموظفين المرتبطين.
- أزرار: تعديل، تعيين كافتراضي، تفعيل/تعطيل، حذف (مع رسالة خطأ واضحة لو محمية).
- زر علوي: **+ سياسة جديدة**.

**نموذج الإنشاء/التعديل (Dialog):**
- معلومات أساسية: الاسم، الوصف، نشطة.
- أساس الراتب: `monthly` / `daily` / `hourly`.
- أيام الشهر: `fixed_30` / `fixed_28` / `fixed_26` / `calendar` / `custom` (مع حقل رقم).
- ساعات العمل اليومية، عدد الساعات قبل احتساب الأوفر، مضاعف الأوفر.
- احتساب الغياب: `daily_rate` / `hourly_rate` / `none`.
- احتساب التأخير: `none` / `per_minute` / `per_hour` + دقائق السماح + سعر الدقيقة.
- وضع الخصومات: `auto` / `manual` / `mixed`.
- ربط البدلات بالحضور (Boolean).
- Engine preset: `standard` / `malaki` / `custom` (نخفيه افتراضياً ونثبته على `standard`).

---

### 2) ربط الموظفين بالسياسات

**أ. من ملف الموظف:** حقل Select جديد "سياسة الراتب" يكتب على `employees.payroll_policy_id` (لو فاضي = السياسة الافتراضية تلقائياً).

**ب. شاشة "تعيين السياسات" داخل صفحة السياسات:**
- جدول الموظفين مع: الاسم، القسم، الفرع، السياسة الحالية، Select لتغييرها.
- فلاتر: قسم، فرع، سياسة حالية.
- **إجراء جماعي:** اختيار عدة موظفين → "تعيين سياسة" → اختيار سياسة → تحديث دفعة واحدة.
- اختصار: زر "تعيين سياسة لقسم كامل" يفلتر بالقسم ويعيّن للجميع.

---

### 3) الملفات الجديدة

```text
src/pages/hr/__internal/payroll-settings/
  ├─ PayrollPoliciesPage.tsx        (الصفحة الرئيسية: قائمة + Tabs)
  ├─ PolicyFormDialog.tsx           (نموذج إنشاء/تعديل)
  └─ PolicyAssignmentTable.tsx      (جدول ربط الموظفين بالسياسات)
src/hooks/hr/
  └─ usePayrollPolicies.ts          (Query/Mutate: list/create/update/delete/setDefault)
```

تعديلات بسيطة:
- `src/components/hr/PayrollSubNav.tsx` — إضافة تبويب "السياسات".
- `src/App.tsx` — تسجيل الراوت الجديد.
- صفحة ملف الموظف الموجودة — إضافة حقل Select للسياسة (لو ما كان موجود).

---

### 4) صلاحيات

استخدام `useHRManagerPermissions` لإخفاء أزرار الإنشاء/التعديل/الحذف عن غير `admin`/`hr_manager`/`super_admin`. RLS بقاعدة البيانات هي خط الدفاع النهائي.

---

### 5) لا migrations

كل الجداول والـRLS والحماية موجودة. فقط React/TS + react-query.

- (ب) كل شيء دفعة واحدة.
