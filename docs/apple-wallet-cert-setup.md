# إعداد Apple Wallet — شهادة البطاقة (Pass Type ID)

لتشغيل «إضافة إلى Apple Wallet» تحتاج خطوة واحدة فقط: إنشاء **شهادة بطاقة** من
بوابة Apple Developer (`developer.apple.com`) وإعطاء الشهادة لفريق التطوير
لإضافتها كسرّ في المشروع. المدة الإجمالية: 10–15 دقيقة.

> المطلوب: حساب Apple Developer Program (المدفوع — 99$ / سنة).
> كل شيء آخر جاهز ومُختبَر (التوقيع، البطاقة، الأزرار في التطبيق).

---

## 1) إنشاء Pass Type ID

1. ادخل إلى [developer.apple.com/account](https://developer.apple.com/account) ← **Certificates, Identifiers & Profiles**.
2. تبويب **Identifiers** ← زر **+** في الأعلى.
3. اختر **Pass Type ID** ← **Continue**.
4. في حقل **Description** اكتب اسماً واضحاً مثل: `بطاقة الولاء الملكي`.
5. في حقل **Identifier** اكتب معرفاً يبدأ بـ `pass.` — مثال:
   `pass.malaky.loyalty`
   (احتفظ بهذا المعرف — ستحتاجه في الخطوة التالية).
6. **Continue** ← **Register**.

## 2) توليد مفتاح خاص + طلب توقيع (CSR) على جهازك

افتح **Terminal** (ماك) أو **CMD** (ويندوز مع OpenSSL) ونفّذ:

```bash
openssl req -new -newkey rsa:2048 -nodes \
  -keyout pass.key \
  -out pass.csr \
  -subj "/CN=pass.malaky.loyalty/O=Malaky Restaurants/C=PS"
```

> استبدل `pass.malaky.loyalty` بمعرّف Pass Type ID الذي أنشأته في الخطوة 1،
> و`Malaky Restaurants` باسم شركتك. يمكن ترك `/C=PS` أو تغييره لدولتك.

ستحصل على ملفين: `pass.key` (المفتاح الخاص — **سرّي جداً**) و `pass.csr`.

## 3) إنشاء الشهادة وتنزيلها

1. في نفس الصفحة السابقة انتقل لتبويب **Certificates** ← زر **+**.
2. اختر **Pass Type ID Certificate** ← **Continue**.
3. اختر الـ Pass Type ID الذي أنشأته ← **Continue**.
4. ارفع ملف `pass.csr` ← **Continue**.
5. نزّل الشهادة (`pass.cer`).

## 4) دمج الشهادة والمفتاح في ملف واحد (p12)

في الـ Terminal على نفس المجلد الذي يحتوي `pass.cer` و `pass.key`:

```bash
openssl pkcs12 -export \
  -out pass.p12 \
  -inkey pass.key \
  -in pass.cer \
  -passout pass:YourStrongPassword123
```

> حدّث كلمة المرور إلى كلمة خاصة بك. (صيغة 3DES القديمة تعمل أيضاً مع
> إضافة `-legacy` — كلتا الصيغتين مدعومتان.)

## 5) إرسال الملفين لفريق التطوير

أرسل لفريق التطوير هذين العنصرين (بأي وسيلة مشفّرة — البريد العادي مقبول):

1. ملف **`pass.p12`**
2. **كلمة مرور** الملف

سيقوم فريق التطوير بإضافتهما كسرّين في المشروع:

| اسم السر                 | القيمة                      |
| ------------------------ | --------------------------- |
| `APPLE_WALLET_PASS_P12`  | محتوى ملف p12 بصيغة base64  |
| `APPLE_WALLET_PASS_P12_PASSWORD` | كلمة مرور الملف |

**لتحويل الملف إلى base64 بنفسك** (اختياري):

```bash
base64 -w0 pass.p12
# انسخ الناتج كاملاً
```

بعد إضافة السرّين تُنشر الدالة تلقائياً ويظهر زر «إضافة إلى Apple Wallet»
على بطاقة الزبون وشاشة التسجيل الناجح في آيفون.

---

## التحقق (اختياري — بدون جهاز آيفون)

نشر فريق التطوير البطاقة وفحصها بالأدوات الآلية:
`openssl pkcs7 -verify` + مطابقة هاشات `sha1` مع `manifest.json`.
الاختبار الوحيد النهائي: فتح صفحة البطاقة على آيفون والضغط على
«إضافة إلى Apple Wallet» ثم «إضافة» — تظهر البطاقة فوراً في المحفظة.

## ملاحظات

- البطاقة لا تتطلب تطبيقاً أو خادم تحديثات: تتحدث تلقائياً عند فتح الصفحة
  (نقاط/رصيد) عبر رمز QR ثابت.
- لتغيير ألوان/شعار البطاقة: عدّل `brand_color` و `logo_url` في برنامج الولاء
  من لوحة الإدارة — تنعكس على البطاقة مباشرة.
- إذا أنشأت لاحقاً بطاقة/برنامجاً جديداً بمعرّف Pass Type ID مختلف،
  تحتاج شهادة جديدة لكل معرّف.
